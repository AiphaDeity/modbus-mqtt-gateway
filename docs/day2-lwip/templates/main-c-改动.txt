# main.c 改动说明（Day2 带 OS 版 · 针对同事重构后的新 main.c）

【背景】同事的新 main.c（origin/main）已经包含：
  - USART1 初始化（MX_USART1_UART_Init）+ printf 重定向（__io_putchar，USER CODE 4 区）
  - ETH 初始化（MX_ETH_Init，内部已配 RMII 全部引脚 + HAL_ETH_Init + 硬件校验和）
  - ETH_NRST(PE12) GPIO（MX_GPIO_Init 里配为输出高）
  - FreeRTOS 启动：osKernelInitialize → MX_FREERTOS_Init → osKernelStart()
    （主循环 while(1) 永远执行不到）

【你要改的只有一处】在 USER CODE 2 区（printf("Gateway boot") 之后）加一行：

    /* USER CODE BEGIN 2 */
    printf("Gateway boot\r\n");
    fflush(stdout);
    m2_ethernet_init();          /* ← 加这一行（bsp/ethernet/ethernet.c 提供） */
    /* USER CODE END 2 */

【为什么在这里调】
  - m2_ethernet_init() 内部：tcpip_init（创建 lwip 内核线程 tcpip_thread）
    → netif_add（ethernetif_init 做 PHY 探测 + HAL_ETH_Start_IT + 建收包线程）
    → 建 DHCP 线程 + 链接线程。
  - 这些线程用 FreeRTOS 创建，调度器（osKernelStart）起来后自动运行。
  - 所以必须在 osKernelStart() 之前调用，且放在 MX_ETH_Init 之后
    （netif_add 里的 PHY 探测要用到已经初始化好的 heth）。

【对照位置】同事 main.c 的 USER CODE BEGIN 2 在 MX_FREERTOS_Init 之前（标准 CubeMX 布局）。
【不需要改】__io_putchar（USER CODE 4 区已有，不要重复写，否则链接报重定义）。
