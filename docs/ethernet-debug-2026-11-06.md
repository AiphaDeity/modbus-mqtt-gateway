# 板子网口故障排查记录

## 现象

| 时间 | 现象 |
|---|---|
| 昨天（11/5） | 同一份代码 ping 通、MQTT 连上 broker，一切正常 |
| 今天（11/6） | 板子在别人手里用过之后，网口 PHY 开始每秒 link up/down 闪断 |
| 后续 | 连串口都时有时无，SWD 能烧录但启动后无输出 |
| 现在 | 串口有输出，静态 IP 设上了，但 ping 不通 |

## 已做的实验

### 实验1：回退到昨天能跑的 commit

- 切到 `bf8f5ee`（昨天验证过 ping 通的版本）
- 编译烧录，断电重启
- 结果：PHY 仍然每秒报 "network cable is not connected / connected"
- 结论：不是今天改的代码问题

### 实验2：换网线

- 换了一根新网线
- 结果：仍然闪断，ping 不通
- 结论：不是网线问题

### 实验3：静态 IP 跳过 DHCP

- 改 `ethernet.c` DHCP_START case，直接设静态 IP `192.168.2.124`
- 串口打印 `STATIC IP: 192.168.2.124`，任务正常跑
- 从电脑 ping 192.168.2.124 → "Destination host unreachable"
- 结论：板子能设 IP，但网口根本收发不出去以太网帧

## 当前状态

- **串口**：正常（任务在调度，telemetry 每 2 秒打印一次）
- **SWD**：正常（能烧录）
- **网口灯**：左边亮（物理上电），右边不亮（无数据收发）
- **PHY 状态**：软件报每秒 link up/down 闪断
- **ping**：不通（ARP 无回应）

## 可能的原因（按概率排序）

| # | 原因 | 怎么确认 |
|---|---|---|
| 1 | LAN8720 PHY 芯片被静电打坏 | 找硬件同事用示波器看 PHY 的 TX_CLK（50MHz）有没有波形 |
| 2 | 网口变压器 / RJ45 座子虚焊或脱焊 | 看 RJ45 座子有没有歪针、脱焊 |
| 3 | PHY 的 NRST 复位脚一直被拉低 | 量 PHY 复位脚电压 |
| 4 | PHY 晶振（25MHz）不起振 | 量晶振两脚电压，或用示波器看波形 |
| 5 | MAC 和 PHY 之间的 RMII 信号断了 | 量 RMII 几个脚的波形 |
